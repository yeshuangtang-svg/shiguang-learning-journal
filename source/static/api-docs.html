学习日志 Agent API

发送一句话，让 Agent 选择工具并处理学习日志。也可以直接使用结构化日志接口。

打开 OpenAPI 3.0 文档

开始一个对话

POST /api/chat
Content-Type: application/json
Authorization: Bearer YOUR_AGENT_TOKEN

{
  "message": "今天弄懂了 Python 列表推导式，把对话中的问题、思路和收获帮我记下来。",
  "request_id": "new-unique-request-id"
}

后续消息附带返回的 session_id。网络重试复用同一个 request_id；新消息使用新编号。配置了 AGENT_API_TOKEN 时才需要 Authorization。

{
  "reply": "模型整理后的回答",
  "session_id": "会话编号",
  "actions": [{"tool": "create_entry", "ok": true, "result": {}}],
  "warnings": []
}

检查 actions 了解实际执行结果。日志保存后模型连接失败时，会返回已保存事实及 warnings，避免重复写入。

内置技能与文档

GET /api/skills 返回八项内置技能的名称与说明。POST /api/chat 可按请求加载技能，调用文档创建、修订、PDF 和技术绘图工具；成功结果包含文档入口或图片 Markdown。文件同步和 PDF 失败会如实返回，已保存的正文保留。

推理强度

GET /api/config 返回 reasoning_effort、reasoning_options、reasoning_hint。POST /api/config 可单独提交 reasoning_effort；default 不传模型推理参数。OpenAI 官方使用 reasoning.effort，第三方兼容服务使用 reasoning_effort。不同模型支持的档位不同，更换模型或接口且未指定档位时重置为 default。

模型连接校验

POST /api/config/models 接收 base_url 与 api_key，获取模型列表且不保存配置。返回 models、verified、message；verified 仅表示列表接口有效响应，不代表对话或工具调用能力。404/405 支持手填回退且 verified=false；鉴权、网络与格式错误须修正后重试。同一地址的空密钥保留已保存值；更换地址须重新填写对应密钥。

日志字段

{
  "date": "2026-10-25",
  "title": "列表推导式练习",
  "subject": "Python",
  "content": "完成列表推导式与循环练习",
  "reflection": "嵌套循环仍需复习",
  "next": "明天练习两个嵌套示例",
  "mood": "okay"
}

必填：date、title、subject、content。无需填写、估算或补充任何时长。reflection 和 next 可分别整理收获与待办；mood 可用 great、good、okay、tired，省略时使用默认值 okay。日期按 Asia/Shanghai 解释。

日志查询参数：date_from、date_to、subject、query、limit（默认100，上限10000）。统计与导出覆盖全部匹配记录。

汇总接口返回 total_entries（日志篇数）、study_days（有记录的日数）、subjects（各主题的 entries 篇数）及 days（各日的 entries 篇数），不统计时长。为兼容旧版备份，底层 minutes 字段仍可读取已有值；新记录省略该字段时保存为 null，不使用占位值。

图文日志与 Markdown 文档

日志正文直接保存 Markdown；上传图片后把返回的 url 写成 ![说明](/api/assets/图片编号)。上传体为 {"name":"图片.png","data_base64":"不带 data: 前缀的 Base64"}。只接受 PNG、JPEG、GIF、WebP，原图最大 8 MiB，按内容去重。读取图片仍需正常的访问令牌，浏览器可先用 fetch 携带 Authorization，再创建 Blob URL。

新建文档请求体为 {"name":"学习笔记.md","content":"# 标题\n正文"}，文件名最大 180 字符且不能含路径，支持 .md/.markdown，UTF-8 正文最大 2 MiB；PATCH 可修改 name 或 content。GET /api/documents 支持 query 搜索文件名和正文，列表不含全文。

导出会同时包含日志、图片和文档；含资源的备份版本为 2，无资源时仍为 1。导入接受这两种版本（最大 256 MiB），全部验证通过后在同一事务合并；相同文档编号更新，其余保留。图片和文档随本机 SQLite 一起保存，导入旧版备份不会删除新增资源。

模型配置

在网页设置 Base URL、模型名与 API Key；服务请求 BASE_URL/chat/completions。使用支持 tools 的兼容模型，密钥不从读取接口返回。本机密钥保存在 data/config.json，也可用环境变量配置。

运行边界

单用户服务默认只监听本机。聊天和相关日志会发送到你选择的模型服务。日志保存在 SQLite，JSON 备份不含聊天历史和密钥。真实模型需自行配置后验证。

未来学习知识

GET/POST /api/future-learning 搜索或收藏；GET/PATCH/DELETE /api/future-learning/{id} 读取、编辑或删除。搜索支持 query 和 status。

仅 title 必填，subject、content、url 选填；url 须为 http(s) 链接。status 为 pending（待学习）、learning（学习中）、done（已学完），默认 pending。收藏独立保存，不计入学习日志统计。

含收藏的完整备份版本为 3，需用应用 1.3 或更新版本恢复；旧版 1/2 备份仍可导入。

文档源文件与 PDF 归档

保存文档后，源文件归档在 data/documents/文档id/。GET /api/documents/{id}/files 同步 MD 并返回路径、source_sha256、pdf_exists 和 pdf_current。插图复制到旁边的 assets 文件夹。

用 MD 制作 PDF 后，POST /api/documents/{id}/pdf 提交 {data_base64, source_sha256}，上限 8 MiB；源文件变动后须重新生成 PDF。POST /api/documents/{id}/open-pdf 和 POST /api/documents/{id}/reveal-md 接收空 JSON，在 Windows 桌面版分别打开 PDF 和定位 MD，不接受任意路径。

JSON 备份不含 PDF 与文件历史，完整迁移请复制整个 data 文件夹。

图片清单

GET /api/images 刷新图片清单，返回 images、index_path、skipped，并写入 data/images/图片清单.json。图片按内容去重，paths 保存所有位置。数据库插图导出到 data/images/，同时扫描 data/documents/ 内的 PNG/JPEG/GIF/WebP（单张不超过 8 MiB，不含历史版本）。

GET /api/images/{id}/content 读取图片。POST /api/images/{id}/open 或 /reveal 接收空 JSON 或 {"location":0}，按 paths 下标打开或定位图片；仅 Windows 桌面版本机调用可用，不接受任意路径。

v1.5 工作区

GET /api/search 统一搜索；GET /api/entries-page 分页摘要；GET/POST /api/links 管理双向关联；GET /api/drafts 获取草稿；GET /api/trash 与 POST /api/trash/{id}/restore 恢复已删除内容。

GET/POST /api/backups 查询或创建完整 ZIP 备份；POST /api/backups/preview 上传 application/zip 获取恢复预览，POST /api/backups/restore 提交预览 token 确认恢复。可选 include_config / restore_config，默认不包含或恢复模型配置。恢复前自动备份当前资料。

POST /api/documents/{id}/generate-pdf 使用本机 Edge 生成当前 PDF；GET /api/documents/{id}/history 查看历史，GET/POST /api/documents/{id}/position 保存阅读位置。所有接口沿用 Agent 令牌鉴权，字段定义见 OpenAPI。
