# v1.6.0：图文学习 Agent 与技术绘图

本版让学习助手能够通过对话创建实际 Markdown 文件、生成 PDF，并将技术配图放进对应讲解段落。模型连接改为先校验接口、选择模型再保存，同时修复 OpenAI 官方接口的对话与工具调用兼容。

## 新增与优化

- **对话生成文档**：创建、修订 MD，默认生成同名 PDF，归档到 `data/documents/<id>/`。回复提供文档入口；源文件变动时阻止过时修订，保留历史文件。模型后续失败会返回已保存结果，PDF 失败不影响已保存的 MD。
- **八项内置技能**：学习文档、图解讲解、资料复盘、公式推导、概念对比、练习纠错、实验分析和学习路线。助手按任务加载，设置页可查看名称与说明。
- **技术绘图**：顺序流程图、带分支/合并/跳连/反馈的架构图、数值矩阵及乘法图、张量形状图、柱状图与折线图。生成的 PNG 随文档归档；矩阵乘法由工具计算，数据图返回各系列最小值、最大值和简单均值。
- **分步 API 设置**：填写地址与密钥后校验并获取模型列表，再选择模型保存；不支持列表的服务可手动填写模型 ID。校验不会保存草稿，更换地址需要重新填写对应密钥。
- **对话兼容修复**：OpenAI 官方地址使用 Responses API，并在工具轮次间保留所需推理上下文；其他兼容服务继续使用 Chat Completions tools。
- **推理强度**：可单独选择与保存档位，更换模型或接口默认恢复为跟随模型设置。具体支持范围取决于模型与服务商。
- **说明更新**：重整 README、源码说明与 API 文档，补充使用示例、技能入口、配图能力和升级步骤。

## 运行与升级

下载 `Shiguang-Learning-Journal-v1.6.0-windows-x64.exe`。运行需要 Windows 10/11 x64 与 WebView2 Runtime；生成 PDF、流程图和技术配图还需要安装 Microsoft Edge 浏览器。

升级前建议在旧版本创建完整备份。关闭旧程序，将新 EXE 放在原目录并保留同目录的 `data/`，再启动。Release 不包含个人日志、文档或模型密钥。`SHA256SUMS.txt` 提供程序校验值，可使用 PowerShell `Get-FileHash -Algorithm SHA256` 核对。

## 能力范围

架构图最多 12 节点、18 条连接；矩阵最多 6×6；张量图最多 6 步；数据图最多 4 系列、12 个类别。复杂内容建议拆分全局与局部图。折线图横轴为等距类别；公式可用 Unicode 或代码表达，当前不渲染 LaTeX/Mermaid，也未接入通用 AI 绘画。

配图在本机生成。AI 对话会把消息、技能说明及实际读取的学习资料发送给所配置的模型服务，应用不会自动读取其他聊天软件。
