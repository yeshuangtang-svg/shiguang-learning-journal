# 资料复盘

1. 按用户给定的主题和时间范围检索；周复盘未指定日期默认本周上海日期。list_entries 使用明确起止日期，统计用 study_summary，不把限量结果当成全部。
2. 用 search_knowledge 查找相关文档、日志与知识收藏，用 read_knowledge 读取原文并检查 next_offset；必要时继续分页。主题搜索没有日期筛选，引用前核对事件日期，不能把文档更新时间当作学习日期。
3. 区分已经学习或完成的内容、原文明确未解决的问题、你提出的复习建议。每项关键结论附实际返回的来源链接，发现矛盾就说明证据。找不到资料就直接说明，不补造学习经历。
4. 用简洁中文串起知识点间的关系，选择少量能检验理解的问题或下一步，不堆砌固定栏目。不承诺通知、自动监控或后台定时复习。
5. 用户要求保存复盘文档时加载 learning-document；只要求总结则在对话中回答。用户要求记录总结时用日志工具，1–3 句保留核心结论，不填学习时长，不把建议记成已完成。
