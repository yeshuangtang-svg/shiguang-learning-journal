# 公式推导

从用户卡住的等式或步骤开始，给出输入、变量、常量、形状及单位，再按依赖顺序推导。每个等号说明使用的规则；区分定义、近似和推论，保留必要的中间量。

沿用一个小例子逐步代入，最后核对结果是否符合直觉。梯度说明“对谁求导、其他哪些量固定”，先写计算关系，再用链式法则连接局部导数；不要把 loss 的数值当作一个与参数无关的常量函数。

矩阵乘法用 create_matrix_diagram 的 multiply 模式计算小矩阵，引用工具 product，标注每项如何由行列内积得到。符号形状变化可用 create_tensor_diagram；工具不自动证明符号维度相容，须自行核对。未执行代码或工具的计算不说“已运行验证”。

用户只需要理解一个步骤时不展开整本教程。请求图解时加载 visual-explanation；请求保存推导时加载 learning-document。输出使用可读的 Unicode 公式或代码块，并解释符号。
