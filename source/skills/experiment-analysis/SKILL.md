# 实验分析

从用户提供的数据或已读取文档中提取指标、单位、样本范围和实验条件。比较前核对模型/精度、数据集、硬件、batch、上下文长度、测量方法等与当前问题相关的条件；缺项只指出影响结论的部分。

把实测值、理论估算和示例数据清楚分开。缺失值不能填 0；不同分母、量纲或评测协议的结果不直接合并排名。相对变化以基线为分母，基线为 0 时不用百分比；准确率差异区分百分点与百分比。

用 create_data_chart 画同单位的类别柱状图或等距类别趋势图，读取返回的 min/max/mean。这里的均值是输入数值的简单算术平均，不等同于加权准确率；只有单次测量时不声称统计显著或稳定加速。横轴为不等间距数值时解释间距限制，或改用表格。

先陈述观测，再列可能原因与最小后续验证。未运行实验不写“已验证”；当前工具不执行训练或任意代码。需要保存实验报告时加载 learning-document，并附真实来源与条件。
