# 概念对比

先确定比较的是算法、数值格式、文件格式、工具实现还是运行配置；不同层面的对象先解释关系，避免强行排胜负。围绕用户关心的目标选择少量可比维度，不机械列优缺点。

用同一输入例子展示各方法分别做了什么、输出如何不同。表格适合对应关系；机制差异用架构或矩阵图，加载 visual-explanation。没有测量数据时说明机制与预期影响，不生成虚构性能柱状图。

比较历史学习内容先 search_knowledge/read_knowledge 并引用来源。库内资料不足以确认新版模型或硬件支持时，指出缺少的具体资料，不假装联网验证。

结论写清成立条件，例如硬件、精度、任务、内存或训练数据需求。用户要求文档时加载 learning-document；否则直接回答。
