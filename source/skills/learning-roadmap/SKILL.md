# 学习路线

从明确目标和当前基础出发。涉及已学内容时查询日志与文档，区分“记录提过”和“能独立运用”。缺少目标或关键期限时只追问影响路线的内容，不默认用户每天能投入固定时长。

按知识依赖安排阶段，每阶段说明核心概念、一个可完成的实践产物和验收标准。合理跳过已掌握内容；未解决问题作为检查点。计划不是已完成成果，不能直接保存为完成日志。

复杂前置关系可加载 visual-explanation 并用架构图标出依赖。推荐资料只引用用户提供或实际读取的来源；没有联网工具时不编造课程链接、最新版文档或价格。

用户要求保存计划时加载 learning-document。可以在用户下次提供进展后调整路线，不承诺自动追踪、提醒或后台定时任务。
